# Changelog

## 0.1.0 — private developer preview

- Deterministic default-deny JSON policy engine and strict JSON loading.
- Host-attested tool/schema hash validation, secret-pattern checks, path/HTTPS host constraints.
- One-time HMAC signed human approval tokens with SQLite replay prevention.
- Optional local HMAC-chained audit (privacy-preserving payload hashes).
- CLI decision inspection, runnable offline demo, tests, release safety documentation.

This is not a public production release or a security certification.
